# Local agent guidance

These repository-local skills supplement `AGENTS.md`. They are intentionally
tool-agnostic: Codex and other coding agents can use the same instructions.

- `skills/rust-cli/SKILL.md` for implementation and validation work.
- `skills/release/SKILL.md` for versioning, crates.io, and GitHub releases.

Keep skills short, operational, and specific to this repository. General
instructions belong in `AGENTS.md`.
